# 农场成熟提醒

原生微信小程序项目，用于记录农场作物成熟时间、浇灌减时和成熟提醒。

## 功能

- 作物可编辑，默认内置水果、蔬菜、菌菇、谷物、花卉完整作物表。
- 支持祈愿坛等级和 5 种游戏天气。
- 天气加成按公式自动计算，并加入对应分类的单次浇灌减时。
- 支持全局默认自己浇灌或男主 100 级浇灌。
- 首页本地倒计时展示成熟状态。
- 微信云开发集合和云函数用于创建种植、浇灌、成熟订阅消息提醒。

## 运行

1. 用微信开发者工具导入本目录。
2. 将 `project.config.json` 里的 `appid` 替换成你的小程序 AppID。
3. 在 `miniprogram/app.js` 和云函数中将 `cloud1-please-replace` 替换成你的云开发环境 ID。
4. 在设置页填写订阅消息模板 ID 和字段 key。
5. 上传并部署 `cloudfunctions` 下的云函数。

## 本地测试
